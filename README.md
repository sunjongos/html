# HTML Custom Tool Generator Skill (`/html`)

**HTML Generator Skill** is a highly specialized Antigravity AI Agent skill that generates 1-off custom HTML tools, dashboards, UI prototypes, and data sorters through natural language prompts.

## Overview
This skill operates with a 3-phase split generation pipeline:
1. **Parse**: Understands interactive requirements (e.g. drag & drop, sliders).
2. **Generate & Split**: Creates `index.html` (Structure), `style.css` (Premium Glassmorphism/Modern UI), and `script.js` (Logic & Interaction).
3. **Loop**: Ensures all generated tools have an actionable "Copy Result" button (e.g., Copy as Markdown) so that outputs can be fed back into the AI.

## Examples Provided
In the `examples/` directory, you can find a `Linear Kanban Board` generated by this skill. 
It uses drag & drop to sort tickets and exports the final prioritization to Markdown format.

## How to use
Add `workflow.md` to your `.agents/workflows` directory and `skill/SKILL.md` to your `.agents/skills/html_generator` directory. 
Trigger it by typing `/html` followed by your prompt.

Example:
`/html --type tool "Create a Linear ticket drag and drop Kanban board with 30 tickets."`
